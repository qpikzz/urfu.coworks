Узнай заполненность коворкинга
не заглядывая внутрь

Система показывает статус коворкинга в реальном времени и позволяет студентам занимать места.

Проблема

Сейчас найти коворкинг означает обойти этажи. Нет информации о занятости ни у студентов, ни у администрации.
Команде трудно найти место, соло-студенту тихий уголок.

Решение. Статусы

Каждой аудитории присваивается статус, который читается с одного взгляда.

Свободно
Доступно
Занято

Решение. Как работает

Для администрации

  • Логи
  • Поиск человека в реальном времени
  • Актуальная информация о доступности коворкингов и спроса на них

Для студента

  • Список аудиторий по институту
  • «Записаться»
  • Режимы «Оставить доступным» и «Занять полностью»
  • Таймер подтверждения
  • 1.Ничего не меняется
  • 2.S2S (Student to student)
  • 3.УрФУ.Учёба
  • 4.Всевузовская интеграция

Ничего не меняется

Точка отсчёта:

  • Ручной поиск
  • Потери времени
  • Нет данных об использовании
  • Нет планирования

S2S (От студентов для студентов)

Простой Telegram-бот с планированием без согласования.

Быстрая проверка идеи на студентах.

Минусы: статус зависит от того, что отмечают сами студенты; проблема с доступностью, обработкой и хранением данных (требуется 2 VPS сервера: иностранный - для работы бота и российский - для хранения данных)

УрФУ.Учеба
