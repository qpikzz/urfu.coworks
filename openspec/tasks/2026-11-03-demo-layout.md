# Задача 1.4. Раскладка демо

## Описание

Собрать раскладку вкладки «Демонстрация»: две колонки на широком экране и рамка телефона с вырезом-камерой по центру сверху. Логика сессий, переключатели и экран приложения в этой задаче не реализуются.

Спецификации:

- DESIGN 5 — рамка телефона: тёмная, с вырезом-камерой по центру сверху, внутри экран приложения.
- DESIGN 6.1 — вкладка «Демонстрация»: две колонки, слева текст, справа макет телефона; контент ограничен по ширине и центрирован.
- DESIGN 6.2 — на планшете те же колонки, макет телефона масштабируется; если колонки не помещаются, они складываются вертикально.
- DESIGN 9 — mobile-first, брейкпоинты 640 и 1024 px, размеры через токены, цвета только токенами.
- FEATURES 4.1 — текст вкладки «Демонстрация».
- RULES 4, 5 — стек React + Vite, короткий поддерживаемый код, проверка сборкой.
