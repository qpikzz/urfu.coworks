# Задача 2.1. Модель данных

## Описание

Описать модель данных приложения: аудитория (название, вуз, этаж, вместимость), студенты-сессии user1–user3, а также загрузка тестовых данных.

- FEATURES 4.2 — каждая сессия это отдельный студент с именем в формате «Имя И.»; у сессии свой вуз, свёрнутые блоки и поиск, а заполненность, статусы, главные, заявки и таймеры общие.
- FEATURES 11 — вузы ИРиТ и ИнЭУ; список аудиторий и начальная заполненность задаются автором вручную.
- FEATURES 1 — вместимость каждой аудитории 5 человек.
- PRODUCT 6.3 — примеры аудиторий из макета: I 101, R 102, K 204.
- PRODUCT 7, RULES 4 — стек React + Vite, вся логика на клиенте.
- RULES 3 — ведение файла задачи.
