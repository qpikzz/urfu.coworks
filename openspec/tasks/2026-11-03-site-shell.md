# Задача 1.3. Каркас сайта

## Описание

Собрать каркас сайта «УрФУ.Коворкинги»: шапку с названием и вкладками «Презентация» и «Демонстрация», переключение вкладок, подвал со ссылкой на GitHub автора. Предусмотреть брейкпоинты 640 и 1024 px.

Спецификации:

- FEATURES 2 — шапка с названием и двумя вкладками, подвал «design & idea by Nikita Shvedov», ссылка на https://github.com/qpikzz.
- DESIGN 6 — раскладка сайта, десктоп/планшет/мобильный, брейкпоинты 640 и 1024 px.
- DESIGN 8 — доступность: видимое кольцо фокуса, интерактивные элементы не меньше 44×44 px.
- DESIGN 9 — mobile-first, `min-width`, `rem`, ссылка автора с `rel="noopener noreferrer"`.
- RULES 4, 5 — стек React + Vite, короткий поддерживаемый код, проверка сборкой.
